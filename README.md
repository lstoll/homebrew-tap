# lstoll tap

```bash
brew tap lstoll/tap
brew install --cask age-plugin-icloud
```

Casks ship notarized GitHub Release zips, not from-source builds.

`Casks/age-plugin-icloud.rb` `version` and `sha256` are meant to be bumped from `lstoll/age-plugin-icloud` on each `v*` release. There is no installable zip until that first tag exists.
